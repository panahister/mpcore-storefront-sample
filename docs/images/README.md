# Visual assets

The Storefront diagrams are repository-native SVG files generated by `scripts/diagrams/storefront.py`
and its local drawing kit. Every README diagram has light and dark variants.

`social-preview.svg` is the editable repository-card source and `social-preview.png` is the 1280 × 640
upload-ready GitHub social preview. Storefront uses the shared cool-spectrum MP visual language while
retaining violet as its reference-product accent.

Do not add customer branding, secrets, private design identifiers, or externally hosted dependencies.
